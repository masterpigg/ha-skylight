# Changelog

## 0.1.0 (2026-11-13)

First release. Read-only.

- Sign in through Skylight's own login page (OAuth 2.0 with PKCE), with automatic token renewal.
- To-do list per chore-chart person, showing today's chores plus overdue ones.
- To-do list per Skylight list (grocery, to-do, and so on).
- Calendar entity with every event shown on the Skylight.
- Reward-points sensor per chore-chart person.
- Sends `Skylight-Api-Version: 2026-10-15`.
